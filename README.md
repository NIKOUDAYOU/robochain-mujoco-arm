# RoboChain MuJoCo Arm with ASR and TTS

本项目是在原有 RoboChain MuJoCo Arm 项目基础上进行的二次开发与功能扩展。原项目主要实现了基于自然语言的机械臂控制，结合 RAG、ROS2、TCP 通信以及 MuJoCo 仿真环境，使用户能够通过文本指令控制机械臂完成相关任务。

在此基础上，本项目进一步加入了语音交互能力，扩展了 ASR 语音识别模块和 TTS 语音合成模块，使系统从“文本输入控制”扩展为“语音输入—语义理解—动作执行—语音反馈”的交互流程，提高了机械臂控制系统的自然交互能力。

## 主要功能

- 支持自然语言控制机械臂
- 支持 MuJoCo 仿真环境中的机械臂动作执行
- 支持 ROS2 节点通信
- 支持 TCP 客户端与服务端通信
- 支持 RAG 检索增强问答
- 新增 ASR 语音识别功能，可将用户语音转换为文本指令
- 新增 TTS 语音合成功能，可将系统回复转换为语音输出
- 支持“语音输入 + 语音反馈”的完整交互流程

## 二次开发内容

相比原项目，本项目主要增加和修改了以下内容：

1. 增加 ASR 语音识别模块  
   用户可以通过语音输入控制指令，系统将语音转换为文本后交给大语言模型进行理解。

2. 增加 TTS 语音合成模块  
   系统在生成文本回复后，可以进一步转换为语音输出，使交互过程更加自然。

3. 调整交互流程  
   原有项目主要以文本输入为主，本项目扩展为语音输入、文本理解、机械臂控制、语音回复的完整流程。

4. 优化用户交互体验  
   通过 ASR 和 TTS 模块，降低了用户操作门槛，使机械臂系统更接近自然语言交互场景。

## 系统流程

整体流程如下：

```text
用户语音输入
      ↓
ASR 语音识别
      ↓
文本指令
      ↓
大语言模型理解
      ↓
RAG 检索增强
      ↓
生成控制指令
      ↓
ROS2 / TCP 通信
      ↓
MuJoCo 机械臂仿真执行
      ↓
TTS 语音反馈




```
运行方式
1. 克隆项目
```
git clone https://github.com/NIKOUDAYOU/robochain-mujoco-arm.git
cd robochain-mujoco-arm
```
2. 安装依赖
```
pip install -r requirements.txt
```
3. 配置API
```
export API_KEY="your_api_key"
```
